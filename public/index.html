自動分類（JEV）

未作成プロジェクトは候補として返し、自動作成しません。

使い方

  1. タスクを作り、完了条件を書いて「エージェントに依頼」を押す（→ エージェント待ち）。
  2. AI は CLI tm inbox で受け取り、作業し、迷ったら tm ask で「あなたの判断待ち」に戻す。
  3. 付箋で答えて再度「エージェントに依頼」。AI は条件を満たしたら tm done で完了する。
  4. 間違いは「履歴」タブや「アクティビティ」から元に戻せる。
